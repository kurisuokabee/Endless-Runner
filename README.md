# Game Description
A 2D pseudo-3D endless runner where players dodge obstacles by switching between three lanes and jumping.

[Gameplay Demo](https://drive.google.com/file/d/1bfFSN9kX3dmJk4zKPpxXhcpJBAK16P5N/view?usp=sharing)

**Mechanics:**
- Three-lane movement and jumping.
- Random obstacle spawning.
- Perspective-based obstacle.
- Health and regeneration system.
- Camera tilt and shake effects.

**Code Limitations:**
- Uses 2D sprites and transform-based movement.
- Perspective and hit detection rely on mathematical calculations instead of Unity physics.
- No Rigidbody, Collider, or physics callbacks.
- Limited to a fixed three-lane perspective system.
